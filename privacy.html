Политика конфиденциальности

Применяется к приложению DSH Drive — персональной интеграции с Google Drive для личного использования. Дата вступления в силу: 14 октября 2026 г.

1. Какие данные обрабатываются

Приложение получает доступ к файлам Google Drive владельца аккаунта, который его авторизовал. Это может включать метаданные файлов (имя, тип, размер, дата изменения, идентификатор), а также содержимое документов Google Docs и таблиц Google Sheets. Приложение не запрашивает и не обрабатывает данные каких-либо других пользователей Google.

2. Как данные используются

Данные используются исключительно для выполнения запросов владельца аккаунта через его локальный инструмент-ассистент:

  • поиск и просмотр метаданных файлов на Диске владельца;
  • чтение содержимого документов и таблиц владельца;
  • создание и обновление документов и таблиц владельца по его прямому запросу.

Данные не используются для рекламы, профилирования, аналитики, обучения моделей или каких-либо иных целей.

3. Где обрабатываются и хранятся данные

Приложение работает полностью на компьютере владельца аккаунта и не имеет собственных серверов и облачной инфраструктуры. Файлы Google Drive при необходимости временно выгружаются в локальную рабочую папку на компьютере владельца и обрабатываются там.

OAuth-токены доступа, выданные Google, хранятся только локально в файле конфигурации на компьютере владельца и защищены правами доступа файловой системы. Токены не передаются третьим лицам.

Если владелец аккаунта по своему запросу поручает ассистенту работу с содержимым документа, это содержимое передаётся поставщику языковой модели, настроенному в его локальном инструменте, в объёме, необходимом для выполнения данного конкретного запроса. Такая передача инициируется только владельцем аккаунта и только для его собственных данных.

4. Передача данных третьим лицам

Приложение не продаёт, не сдаёт в аренду и не передаёт данные Google каким-либо третьим лицам, кроме описанного выше случая обработки запроса владельца аккаунта. Приложение не передаёт данные рекламным сетям, брокерам данных или иным организациям.

5. Использование в соответствии с политикой Google

Использование приложением информации, полученной из API Google, соответствует Google API Services User Data Policy, включая требования Limited Use. В частности:

  • данные Google используются только для предоставления пользователю функций, описанных в настоящей политике и на главной странице приложения;
  • данные Google не передаются третьим лицам, кроме случаев, когда это необходимо для предоставления функций приложения, требуется законом или прямо разрешено пользователем;
  • данные Google не используются для рекламы, а также для обучения или улучшения обобщённых моделей машинного обучения;
  • доступ человека к данным Google возможен только с явного согласия владельца аккаунта, в целях безопасности, для соблюдения закона или для внутренних операций, и только в объёме, необходимом для этих целей.

6. Хранение и удаление данных

Приложение не хранит копии данных Google дольше, чем это необходимо для выполнения конкретного запроса. Владелец аккаунта может в любой момент:

  • удалить локальные копии файлов, выгруженные в рабочую папку;
  • отозвать доступ приложения на странице myaccount.google.com/permissions;
  • удалить локальный файл конфигурации с OAuth-токеном.

После отзыва доступа приложение немедленно теряет возможность обращаться к Google Drive.

7. Безопасность

Обмен данными с Google выполняется только по защищённому протоколу HTTPS. Доступ ограничен областью https://www.googleapis.com/auth/drive, запрошенной владельцем аккаунта при авторизации.

8. Дети

Приложение не предназначено для использования детьми и не собирает данные детей.

9. Изменения политики

Актуальная версия политики всегда доступна на этой странице. При существенных изменениях дата вступления в силу обновляется.
